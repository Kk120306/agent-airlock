Prototype answer

The model is viable only when Admission Record publication and Candidate creation share one recoverable receiver operation, and when Promotion still requires a separate local Validation result plus the existing Promotion journal. A receipt, checkpoint, witness, or blockchain digest never advances Canonical State by itself.
